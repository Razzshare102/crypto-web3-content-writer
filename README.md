# Human-Like Crypto & Web3 Content Writer

An AI-powered writing skill for natural, authentic, research-driven content across Crypto, Web3, Blockchain, DeFi, AI, Trading, and InfoFi.

## What it does

- Human-like X (Twitter) posts and threads
- Educational content with real examples
- Project updates and announcements
- DeFi, RWA, AI, and Blockchain explained simply
- Trading and perpetual DEX content
- InfoFi and creator economy content
- Campaign and community posts

## Philosophy

**Research first. Write naturally. Deliver real value.**

Write like a real human, not a generic AI assistant. Never invent project features, partnerships, statistics, or rewards. Separate verified facts from personal opinions.
